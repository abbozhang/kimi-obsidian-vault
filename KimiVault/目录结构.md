# KimiVault 目录结构

> 更新日期：2026-02-23

```
KimiVault/
├── 📓 Daily/                    # 每日日记
│   └── YYYY-MM-DD.md            # 结构：工作(已办/待办/灵感) + 生活(已办/待办/灵感)
│
├── 📥 Inbox/                    # 长文材料
│   ├── 待读/                    # 未读（标题含来源：小红书/小宇宙等）
│   └── 已读/                    # 已读（用户自己挪）
│
├── 🗂️ MOC/                      # 索引页
│   ├── 日记索引.md
│   ├── 灵感索引.md
│   └── 项目索引.md
│
└── 🧠 Knowledge/                # 知识库
    └── 按主题分类               # 从 Daily/Inbox 整理而来（时机由用户定）
```

## 各目录说明

### Daily/
- **命名格式**：`YYYY-MM-DD.md`
- **内容结构**：
  - 工作
    - 已办
    - 待办
    - 灵感
  - 生活
    - 已办
    - 待办
    - 灵感

### Inbox/
- **待读/**：来不及看的长文材料，标题体现来源（如：小红书-xxx、小宇宙-xxx）
- **已读/**：用户自己挪入，不自动处理

### MOC/
- 索引页，用于快速导航

### Knowledge/
- 存放整理后的主题内容
- 从 Daily（灵感发酵）和 Inbox（阅读消化）整理而来
- **整理时机**：由用户决定，需要时告知

## 定时任务

- **每天 8:00**：AI 日报
- **每周六 8:00**：生成周报（工作周报 + 生活周报，汇总周一至周五内容）
