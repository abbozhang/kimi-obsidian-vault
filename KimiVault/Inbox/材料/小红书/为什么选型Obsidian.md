## 核心观点

### 为什么选 Obsidian 而不是 Notion/印象笔记/Roam
- **数据主权**: 本地 Markdown，AI 可直接访问，无需 API
- **插件生态**: 1000+ 插件，模块化搭建
- **AI 友好**: Markdown 是 AI 的母语

### 5 个核心插件
1. **Dataview** — 数据库引擎，让笔记可查询
2. **Templater** — 自动化引擎，动态模板
3. **Kanban** — 项目管理看板
4. **Tasks** — 智能任务系统
5. **Advanced Tables** — 表格数据处理

### 效率提升数据
- 查找笔记: 3分钟 → 3秒（60倍）
- 写日报: 10分钟/天 → 10秒/天（年省60小时）
- 任务遗漏率: 30% → 0%
