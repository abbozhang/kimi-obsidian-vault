## 用途

- 每日笔记
- 灵感记录
- 项目整理

## 结构

```
KimiVault/
├── 📓 Daily/        # 每日笔记
├── 💡 Inbox/        # 灵感收件箱
├── 🌱 Fleeting/     # 闪念笔记
├── 🏷️ MOC/          # 索引页
├── 📁 Projects/     # 项目笔记
├── 📚 Reading/      # 阅读笔记
└── 🖼️ Attachments/  # 附件
```
