# 笔记写入规则

> 记录写入笔记时的注意事项和规则

## 基本规则

### 1. 不确定写到哪里时
**必须先读 `KimiVault-Structure.md`**，确认目录结构后再写入。

### 2. 每日日记（Daily/）
- **命名格式**：`YYYY-MM-DD.md`
- **内容结构**：
  - 工作
    - 已办
    - 待办
    - 灵感
  - 生活
    - 已办
    - 待办
    - 灵感

### 3. 材料存放（Inbox/）
- **待读/**：来不及看的长文材料
  - 标题体现来源，如：`小红书-为什么选型Obsidian.md`、`小宇宙-张扎拉访谈.md`
- **已读/**：用户自己挪入，不自动处理

### 4. 知识库（Knowledge/）
- 存放整理后的主题内容
- 从 Daily（灵感发酵）和 Inbox（阅读消化）整理而来
- **整理时机**：由用户决定，需要时告知

## 重要提醒

- 不要简略处理旧文件内容，要原封不动保留
- 合并文件时，确保不丢失原始内容
- 提交后必须推送，不能「放在那里不管」
