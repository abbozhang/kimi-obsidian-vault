# KimiVault 目录结构

> 更新日期：2026-02-23

## 完整文件结构

```
KimiVault/
├── 📓 Daily/                          # 每日日记
│   └── YYYY-MM-DD.md                  # 四部分内容：
│                                       # 1. 今日工作（已做/待办/灵感）
│                                       # 2. 今日生活（已做/待办/灵感）
│                                       # 3. Claw日志（每天20:59定时写入）
│                                       # 4. AI大事记（每天8:00定时写入）
│
├── 📥 Inbox/                          # 临时存放
│   ├── 材料/                          # 长文材料
│   │   └── 文件名.md                  # 包含：来源、原文链接、内容
│   └── 其他有的没的                   # 用户自己写或让我放
│
├── 🧠 Knowledge/                      # 知识库
│   └── 周报/                          # 工作周报 + 生活周报
│                                       # 每周六早上定时生成
│
├── 🗂️ MOC/                            # 索引链接
│   ├── 日记索引.md
│   └── 灵感索引.md
│
└── 🧠 memory/                         # 记忆规则
    ├── 红线准则.md                    # Git提交后必须推送
    ├── 笔记写入规则.md                # 写入笔记的注意事项
    └── 目录结构.md                    # 本文件

├── 🔧 skills/                         # 技能文件
│   └── obsidian/
│       ├── SKILL.md
│       ├── _meta.json
│       └── .clawhub/origin.json
```

## 定时任务

| 时间 | 任务 | 写入位置 |
|------|------|----------|
| 每天 8:00 | AI大事记 | Daily/YYYY-MM-DD.md → AI大事记 |
| 每天 20:59 | Claw日志 | Daily/YYYY-MM-DD.md → Claw日志 |
| 每周六早上 | 周报生成 | Knowledge/周报/工作周报.md + 生活周报.md |

## 笔记写入规则（重要）

**优先级：**
1. **用户明确指定位置** → 以用户为准
2. **用户未指定** → 扫描本目录结构，自行决定最合适位置

**决策流程：**
- 工作相关 → Daily/今日工作
- 生活相关 → Daily/今日生活  
- 长文材料 → Inbox/材料/
- 灵感碎片 → Daily/想法
- 整理后的知识 → Knowledge/
