## AI大事记

### 1. OpenAI关闭Sora应用——战略收缩聚焦核心业务
**来源**: The Hollywood Reporter, ReadAboutAI  
**链接**: https://www.hollywoodreporter.com/business/digital/openai-shutting-down-sora-ai-video-app-1236546187/

OpenAI宣布关闭其AI视频生成应用Sora,这标志着公司战略重心的重大调整。据AI for Humans播客和多家媒体报道,OpenAI正在从实验性产品收缩至企业服务、编程工具和前沿模型竞争三大核心领域。这一决定并非技术失败,而是在激烈竞争压力下的资源聚焦——Anthropic的Claude在企业市场快速崛起,迫使OpenAI重新评估产品优先级。

**行业意义**: 这预示着AI行业从"广撒网"进入"精准打击"阶段,非核心产品线将被快速淘汰。

### 2. OpenAI完成1220亿美元融资,估值达8520亿美元
**来源**: 36氪, Fortune, The Economist  
**链接**: https://eu.36kr.com/zh

OpenAI完成史上最大规模融资之一,融资1220亿美元(一说1100亿美元),估值飙升至8520亿美元(另一说7300亿美元)。本轮融资由软银(300亿美元)、亚马逊(500亿美元)和英伟达(300亿美元)领投。值得注意的是,亚马逊的投资与OpenAI购买其Trainium芯片挂钩,标志着OpenAI从依赖微软Azure转向多云战略。公司最新年化营收已超250亿美元,并计划2026年下半年IPO。

**行业意义**: 巨额融资凸显AI军备竞赛进入新阶段,同时揭示AI公司烧钱速度惊人——OpenAI 2026年预计亏损140亿美元。

### 3. Claude Code开源泄露——51万行代码引发行业震动
**来源**: 36氪  
**链接**: https://eu.36kr.com/zh

疑似Claude Code的完整源码(51万行)遭到泄露并开源,引发全网狂欢。这一事件被业内称为"炸裂级"突破,因为开发者可以直接查看包括手写注释在内的核心实现细节。如果泄露属实,这将是AI编程助手领域最大的技术泄露事件,可能加速整个行业的技术扩散。Anthropic尚未对此事发表官方声明。

**行业意义**: 开源与闭源之争再次升温,核心技术保护面临巨大挑战。

### 4. ChatGPT变身购物发现引擎——AI电商大战开启
**来源**: CNBC, Axios, OpenAI Blog  
**链接**: https://www.cnbc.com/2026/03/24/openai-revamps-shopping-experience-in-chatgpt-after-instant-checkout.html

OpenAI宣布在ChatGPT中推出全新"产品发现"功能,支持可视化浏览、价格对比和实时产品信息,并通过"代理商务协议"(ACP)让商家直接向ChatGPT提供产品目录。沃尔玛已率先入驻,用户可在ChatGPT中发现商品,但结账仍在商家平台完成。这标志着AI从"对话工具"向"行动接口"转型,直接挑战谷歌购物和亚马逊。

**行业意义**: AI搜索正在重新定义电商入口,传统搜索引擎面临生存挑战。

### 5. GitHub Copilot在PR中插入广告引发开发者愤怒
**来源**: The Register, Windows Central  
**链接**: https://www.theregister.com/2026/03/30/github_copilot_ads_pull_requests/

GitHub Copilot开始在自动生成的Pull Request中插入工具推广"小贴士",被开发者视为变相广告。社区强烈反弹后,GitHub迅速撤回该功能。这一事件触及了AI工具信任边界的敏感点——开发者可以容忍AI辅助编程,但绝不接受代码审查流程被商业化污染。GitHub产品负责人Martin Woodward确认已禁用此功能。

**行业意义**: AI工具的商业化边界问题浮出水面,用户信任比短期收入更重要。
