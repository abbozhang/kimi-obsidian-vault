## AI大事记

### 1. OpenAI正式关闭Sora视频应用
**来源**: The Verge / Axios  
**时间**: 2026-03-25  
**简述**: OpenAI宣布将关闭其视频生成应用Sora,这标志着AI视频生成领域的一次重大调整。尽管Sora在2024年底盛大发布,甚至与迪士尼达成了数百万美元的合作,但在面对Kling、Veo 3和Runway等竞争对手时逐渐失去优势,最终在2026年初几乎从市场对话中消失。OpenAI表示关闭原因是为了聚焦资本、算力和企业级产品,应对来自Anthropic和Google的激烈竞争。这成为近期科技史上最快产品失败案例之一。  
**原文链接**: https://gradientsignal.com/digest/2026-03-25

### 2. Yann LeCun创立AMI Labs,押注具身智能超越纯语言模型
**来源**: LabLA / Multiple Sources  
**时间**: 2026-03-25  
**简述**: Meta首席AI科学家Yann LeCun宣布创立AMI Labs(Advanced Machine Intelligence),明确提出"纯语言模型永远无法达到接近人类的智能"的观点。该实验室将专注于具身智能研究,要求AI首先理解物理世界。初期应用目标包括医疗、机器人、可穿戴设备和工业自动化。投资方包括Nvidia、三星、丰田风投和Bezos Expeditions等科技巨头。这标志着AI研究范式从纯文本理解向物理世界交互的重大转向。  
**原文链接**: https://www.labla.org/latest-ai-model-releases-past-24-hours/new-ai-model-releases-announcements-march-25-2026-the-stuff-that-actually-matters-today-beyond-openai-and-google/

### 3. MiniMax M2.5模型引发中国AI性价比革命
**来源**: LabLA / devFlokers  
**时间**: 2026-02-12(持续热议至3月25日)  
**简述**: 上海AI初创公司MiniMax推出的M2.5模型虽发布于2月12日,但在3月25日仍是开发者社区最热议的话题。该模型以1/10到1/20的价格提供与GPT-5或Claude Opus 4.6相当的能力,在编程、视觉内容生成等领域表现出色。这一定价策略引发中国AI市场激烈竞争,推动大模型从"参数竞赛"转向"性价比竞争",为全球初创企业和中小企业提供了更可负担的AI解决方案。

### 4. NVIDIA Vera Rubin平台订单达1万亿美元
**来源**: UniFuncs Report / Multiple Sources  
**时间**: 2026-03-16-20(GTC 2026大会期间)  
**简述**: NVIDIA在GTC 2026大会上(3月16-20日)展示的新一代AI超算平台Vera Rubin获得了惊人的1万亿美元订单。该平台包含六款新芯片,包括专为AI优化的Vera CPU、配备第三代Transformer引擎的Rubin GPU,以及NVLink 6互连技术(提供260 TB/s带宽)。相比前代Blackwell平台,Rubin实现了每token成本降低10倍、所需GPU数量减少4倍的突破。预计将在2026年下半年开始部署首批千兆瓦级数据中心,标志着AI基础设施进入新纪元。  
**原文链接**: https://s.unifuncs.com/?sid=44db46f8-60ba-4979-a3c1-6ca4dd20ff15

### 5. Anthropic Claude推出Computer Use功能,AI进入"执行代理"时代
**来源**: Multiple Sources  
**时间**: 2026-03-23-25  
**简述**: Anthropic为其Claude助手推出了革命性的"Computer Use"(电脑控制)功能,允许AI在用户授权下通过模拟鼠标和键盘操作自动完成跨应用的复杂任务流程。这标志着AI从"对话助手"正式演进为"执行代理",可以实际操作电脑完成工作。该功能引发了行业关于OpenClaw等开源项目的热议,以及对AI操作边界和安全性的深入探讨。结合OpenAI GPT-5.4的原生计算机使用能力,2026年被视为"Agentic AI"(智能体AI)进入实用化爆发期的关键节点。  
**原文链接**: https://s.unifuncs.com/?sid=44db46f8-60ba-4979-a3c1-6ca4dd20ff15
